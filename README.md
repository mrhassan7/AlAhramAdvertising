# موقع الأهرام للدعاية والإعلان

موقع ثابت (HTML + CSS + JavaScript) — بدون Node ولا build ولا قاعدة بيانات.
بيشتغل بمجرد ما ترفع الملفات على أي استضافة.

---

## المعاينة محلياً

افتح `index.html` مباشرة بالمتصفح، أو — وهذا الأفضل لأن بعض المتصفحات بتمنع تحميل
الملفات المحلية — شغّل خادم صغير:

```bash
node dev-server.js
```

ثم افتح `http://localhost:4321`.

> `dev-server.js` و `.claude/` للتطوير فقط — **ما بترفعهم على الاستضافة**.

---

## الرفع على الاستضافة

ارفع هذه الملفات والمجلدات فقط:

```
index.html  services.html  products.html  portfolio.html  contact.html
assets/
```

بيشتغل على: Hostinger، cPanel، GitHub Pages، Netlify، Cloudflare Pages، أو أي
استضافة ثابتة. ما في أي إعداد إضافي مطلوب.

---

## أين أعدّل ماذا؟

| بدك تغيّر | افتح |
|---|---|
| رقم الواتساب، الإيميل، العنوان، الدوام، روابط السوشال | `assets/js/site.config.js` |
| أي نص في الواجهة (عربي أو إنجليزي) | `assets/js/i18n.js` |
| الخدمات، المنتجات، معرض الأعمال | `assets/js/data.js` |
| الألوان والخطوط والمسافات | `assets/css/tokens.css` |
| شكل العناصر والتفاصيل | `assets/css/main.css` |

**كل بيانات التواصل في مكان واحد.** غيّر رقم الواتساب في `site.config.js` وبيتغيّر
في كل الموقع — الزر العائم، وكل أزرار «اطلب عرض سعر»، والفوتر، وصفحة التواصل.

## إضافة منتج جديد

افتح `assets/js/data.js` وضيف سطر داخل `products`:

```js
{ id: 'p85', cat: 'gifts', img: 'my-product',
  ar: { name: 'اسم المنتج', desc: 'وصف قصير للمنتج.' },
  en: { name: 'Product name', desc: 'Short product description.' } },
```

- `cat` لازم يكون واحد من الـ id الموجودة في `productCats`.
- `img` هو **اسم الملف بدون الامتداد**. حطّ الصورة في مكانين:
  - `assets/img/products/my-product.jpg` — الحجم الكبير (عرض ~1100px)
  - `assets/img/products/thumb/my-product.jpg` — المصغّرة (عرض ~620px)
- إذا خلّيت `img: ''` بيظهر مكان الصورة أيقونة أنيقة مكتوب تحتها «الصورة قريباً»
  — مش صورة مكسورة. أول ما تحط الصورة بتظهر لحالها.
- ضيف `contain: true` للصور اللي ما بتحتمل القص (زي صور الأجهزة المربّعة) —
  بتظهر كاملة داخل الكرت بدل ما تنقص من الأطراف.

### إظهار سعر ثابت وكود صنف

ضيف `price` (رقم) و`code` (نص) لأي منتج:

```js
{ id: 'fr13', cat: 'photoframes', img: 'frame-13', code: 'B43', price: 6, … }
```

- السعر بيظهر مكان الوصف على الكرت، بعملة `currency` من `site.config.js` (حالياً ₪).
- الكود بيظهر جنب اسم القسم على الكرت، وبينضاف لرسالة الواتساب حتى تلاقي الصنف
  على الرف مباشرة.
- المنتجات بدون `price` بتضل تعرض الوصف وزر «اطلب عرض سعر» زي ما كانت.

### أقسام فرعية داخل التصنيف (زي أحجام الألبومات والفريمات)

إذا بدك تجمّع منتجات تحت عنوان فرعي داخل نفس التصنيف، ضيف حقل `group`:

```js
{ id: 'al01', cat: 'albums', img: 'album-leather-15x20-120-01',
  group: { ar: 'جلد 15×20 — 120 صورة', en: 'Leather 15×20 — 120 Photos' },
  ar: { name: 'تصميم 1', desc: '…' },
  en: { name: 'Design 1', desc: '…' } },
```

الموقع بيرسم عنوان القسم أوتوماتيكياً أول ما يتغيّر الـ`group`، فالمنتجات اللي إلها
نفس المجموعة **لازم تكون متتالية** في المصفوفة. واسم المجموعة بينضاف لرسالة
الواتساب حتى يعرف الزبون بالضبط أي حجم بيسأل عنه.

## العروض (باقات السعر المقطوع)

قسم العروض في أعلى الصفحة الرئيسية بيتغذّى من `offers` في `assets/js/data.js`:

```js
{
  id: 'wedding',
  img: '',            // اسم البوستر بدون امتداد — اتركها فارغة إذا ما في بوستر
  price: 400,         // بعملة currency من site.config.js
  ar: { title: 'بكج الأعراس', tagline: 'نصنع حضورك في كل مناسبة',
        items: ['بوسترين…', '1000 فنجان قهوة مطبوع', 'عباية عريس مطبوعة'] },
  en: { title: 'Wedding Package', tagline: '…', items: ['…'] }
}
```

- **البوسترات موجودة** في `assets/img/offers/` (عرض 900px). لتبديل بوستر،
  استبدل الملف بنفس الاسم. لإضافة عرض جديد ببوستر، حطّ الصورة هناك وحطّ اسمها
  في `img` — وخلّيها فارغة لو ما في بوستر، هيك ما بينطلب ملف مش موجود.
- **لإخفاء عرض مؤقتاً:** ضيف `active: false` بدل ما تحذف السطر.
- زر العرض بيفتح واتساب برسالة فيها اسم الباقة وسعرها.
- القسم موجود في `index.html`. لعرضه في صفحة ثانية، انسخ نفس الـ`<section>`
  ولازم يكون فيه `<div class="offers" data-render="offers"></div>`.

## إضافة عمل لمعرض الأعمال

نفس الطريقة، داخل `works`:

```js
{ img: 'client-project', cat: 'social',
  ar: { t: 'اسم العمل', c: 'اسم العميل' },
  en: { t: 'Project name', c: 'Client name' } },
```

الصور في `assets/img/portfolio/` و `assets/img/portfolio/thumb/`.
ضيف `wide: true` للأعمال العريضة (البانرات والستيكرات) عشان تاخذ عمودين،
و`contain: true` للشعارات والستيكرات الطويلة عشان تظهر كاملة بدون ما تنقص من الأطراف.

## اللغة

الموقع عربي/إنجليزي بزر تبديل في الهيدر. الاختيار بينحفظ في المتصفح
(`localStorage`) فالزائر ما بيحتاج يبدّل كل مرة.

كل نص في الصفحات مربوط بمفتاح عبر `data-i18n="مفتاح"`. لتعديل نص: دوّر على
المفتاح في `assets/js/i18n.js` وغيّر القيمة في `ar` وفي `en`.

الاتجاه (RTL/LTR) بينقلب أوتوماتيكياً — الـCSS مكتوب بخصائص منطقية
(`margin-inline`, `inset-inline`…) فما في ملف CSS منفصل للإنجليزي.

## نموذج «اطلب عرض سعر»

الموقع ثابت وما فيه خادم يستقبل رسائل، فالنموذج **بيبني رسالة واتساب منسّقة
وبيفتحها** مباشرة. الرسالة بتوصلك فوراً وما في تكلفة استضافة إضافية،
والموقع ما بيخزّن أي بيانات للزائر.

إذا لاحقاً بدك الرسائل توصل على الإيميل كمان، أسهل حل هو
[Formspree](https://formspree.io) — بيتضاف بسطرين في `contact.html`.

## ملاحظات مطلوب متابعتها

1. **الخريطة** في `contact.html` تبحث عن «واد الهرية، الخليل» ومش دبوس دقيق.
   افتح موقعك على Google Maps وانسخ العنوان، وحطّه في `mapQuery` داخل
   `site.config.js`.
2. **الشعار** مستخرج من تصميم إعلاني بجودة عالية. إذا عندك الملف الأصلي
   (AI / PSD / PNG بخلفية شفافة) استبدل `assets/img/logo/mark.png` وبتصير أحدّ.
3. **صور ناقصة**: ورق السبلميشن والكوشيه، حبر الإيكو سولفنت والبيجمنت، شادر
   البلوك أوت والمش، فينيل الفليكس والفلوك، الألبومات المطبوعة، وبعض الهدايا
   الدعائية — بتظهر حالياً بأيقونة «الصورة قريباً» (14 صنف من أصل 224). أول ما
   تصوّرها حطّها بالأسماء المذكورة في `data.js` وبتظهر لحالها.
4. **مقاسات ورق ميتسوبيشي** مكتوبة على العبوة بالإنش مش بالسنتيمتر:
   4×6 إنش (102×152 مم)، 5×7 إنش (127×178 مم)، 6×8 إنش (152×203 مم).
   الموقع بيعرضها بالإنش مع ما يقابلها بالمليمتر.
5. **أسعار الفريمات** مقروءة من التصاميم نفسها. لما يتغيّر سعر، عدّل `price` في
   `data.js` — وانتبه إن صورة التكبير هي التصميم الكامل والسعر مطبوع عليها،
   فلازم تستبدل الصورة كمان.

  js/site.config.js   بيانات التواصل  ← عدّل هنا
